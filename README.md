# IMDB Movie Dataset Analysis — Power BI Dashboard

 Project Overview

This project analyses **10,000+ movies** from the IMDB dataset (2005–2024) to uncover trends in genre popularity, audience ratings, movie runtime, and production volume over time.

The goal was to transform raw movie data into a clean, interactive Power BI dashboard that allows users to explore the dataset visually and draw meaningful insights about the film industry.

---

## Business Questions Answered

- Which genres produce the most movies?
- How has movie production volume changed year over year?
- What is the distribution of audience ratings across all movies?
- How does runtime vary across the dataset?
- Which primary genres dominate the industry?

## Key Insights

1. **Documentary and Drama** are the most produced genres, significantly ahead of Comedy and Horror
2. **Movie production grew steadily** from 2010 to 2024, peaking around 2019–2022
3. **Average audience rating clusters around 6–7**, forming a normal distribution
4. **Most movies run between 80–120 minutes**, with a sharp drop-off beyond 150 minutes
5. **Drama dominates as the primary genre**, followed by Documentary and Comedy
