# IMDb Movie Dataset Analysis
### Power BI Dashboard | SQL | Data Visualisation

![Dashboard Preview](IMDB%20Analysis%20Dashboard.jpg)

---

## 📌 Project Overview

This project analyses 10,000+ movies from the IMDb dataset (2005–2024) to uncover trends in genre popularity, audience ratings, movie runtime, and production volume over time.

I used SQL to extract and query the raw data, then built an interactive Power BI dashboard to make the insights explorable and visual. The goal was to answer real business questions about the film industry — not just describe the data, but draw meaning from it.

---

## ❓ Business Questions Answered

- Which genres produce the most movies?
- How has movie production volume changed year over year?
- What is the distribution of audience ratings across all films?
- How does runtime vary across the dataset?
- How have average ratings and runtimes trended from 2005 to 2024?

## 💡 Key Insights

1. Documentary and Drama are the most produced genres — significantly ahead of Comedy and Horror
2. Movie production grew steadily from 2010 to 2024, peaking around 2019–2022
3. Average audience ratings cluster around 6–7, forming a near-normal distribution
4. Most movies run 80–120 minutes, with a sharp drop-off beyond 150 minutes
5. Drama dominates as the #1 primary genre, followed by Documentary and Comedy
6. Average rating and runtime stayed stable over 20 years, suggesting industry-wide standardisation
